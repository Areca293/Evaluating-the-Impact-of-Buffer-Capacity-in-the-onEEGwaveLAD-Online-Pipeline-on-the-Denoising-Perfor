# onEEGwaveLAD Framework

Unsupervised EEG artefact removal framework using wavelet decomposition and Extended Isolation Forest.

## Overview

This project implements an online EEG denoising pipeline that operates on continuous signals without requiring clean reference data. The framework combines:

- Real-time windowing with power-of-2 sample adjustment
- Multi-level discrete wavelet transform (DWT)
- Extended Isolation Forest for unsupervised anomaly detection
- Adaptive artefact attenuation in the wavelet domain
- Moving buffer mechanism for temporal context

## Dataset Format

This framework is designed for the **ERP CORE N170** dataset but can be adapted to other EEG datasets. The expected format is:

- **File format**: EEGLAB `.set` files
- **Channels**: 30 EEG channels (standard 10-20 montage) + 3 EOG channels
- **EEG channels**: FP1, F3, F7, FC3, C3, C5, P3, P7, P9, PO7, PO3, O1, Oz, Pz, CPz, FP2, Fz, F4, F8, FC4, FCz, Cz, C4, C6, P4, P8, P10, PO8, PO4, O2
- **EOG channels**: HEOG_left, HEOG_right, VEOG_lower
- **Sampling rate**: 256 Hz (after downsampling) or higher
- **Event markers**: For ERP-based quality metrics (optional)

### Configuration Parameters

Key parameters in **Cell 6** that you can adjust:

```python
# Data selection
subject_id = "1"               # Which subject to process (1-40)

# Windowing parameters
RTWL = 1000                    # Real-time window length in milliseconds

# Denoiser parameters
Bs = 20                        # Buffer size (number of windows to keep)
IFS = 512                      # Isolation Forest sample size
Ta = 0.55                      # Anomaly threshold (0-1, higher = stricter)
Es = 35                        # Expansion size (temporal context around anomalies)

# Debug settings
debug_ch_idx = 0               # Channel index for detailed debugging
max_simulation_time_sec = 60.0 # Stop after N seconds (for testing)
```

**Parameter recommendations:**

- **Bs**: 20 is optimal based on convergence analysis (see Cell 19-20)
- **Ta**: 0.55 balances sensitivity vs specificity
- **Es**: 35 provides adequate temporal smoothing
- **RTWL**: 1000ms (1 second) is standard for ERP studies

### 3. Extreme Value Diagnostics (Cell 2)

**Purpose:** Detect outliers and understand metric distributions

**Analysis performed:**

- Percentile distribution (1%, 5%, 25%, 50%, 75%, 95%, 99%)
- Multi-level threshold checks (|value| >= 80, 50, 30, 10)
- Identifies extreme positive and negative values

**Target metrics:** SNR-Diff, PSNR-Diff

**When to use:** Data quality control after batch processing

**Interpretation:**

- Values at 99th percentile: top 1% performance
- Values at 1st percentile: bottom 1% (potential issues)
- High counts at |value| >= 80: possible artefacts or processing errors
